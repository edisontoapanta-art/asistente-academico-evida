# Asistente Académico EVIDA

Herramienta web de una sola página para que estudiantes universitarios desarrollen, documenten, revisen y entreguen actividades ACD, APE y AA siguiendo el ciclo E → V ↺ → I → D → A (Evidencia, Verificación, Interpretación, Decisión, Argumentación).

EVIDA es una propuesta didáctica pendiente de validación empírica. La herramienta ofrece retroalimentación orientativa y no sustituye la evaluación docente. Los ejemplos incluidos son orientativos, no actividades oficiales.

Uso: abrir index.html en el navegador (no requiere instalación ni internet) o usar la versión en GitHub Pages. Los datos se guardan en el navegador; usa Exportar/Importar (.json) para copias de seguridad.

Propuesta metodológica EVIDA: Ing. Edison Oswaldo Toapanta Mendoza, MAE (Documento Fundacional v1.0, 2026).
